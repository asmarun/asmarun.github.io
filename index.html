Reducing platform cost

FinOpsGoldilocksKubeCostEnvoy GatewayCloudflare Tunnel

Problem
Platform cost needed continuous control as clusters, workloads and environments grew.
Approach
  • Regular team cost reviews, with pod and node right-sizing driven by utilisation data (Goldilocks, KubeCost).
  • Moved high-write workloads from Blob Storage to File Share and Table Storage to avoid excessive write-operation charges.
  • Replaced Azure Application Gateway with Cloudflare Tunnel and Envoy Gateway for two of the three products.
  • Migrated node pools to a newer, more cost-efficient VM SKU family.
Result
Lower cost and an improved security posture, with the Envoy and Cloudflare pattern now running in production.
